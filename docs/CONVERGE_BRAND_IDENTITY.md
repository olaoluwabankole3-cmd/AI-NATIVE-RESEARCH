# Converge — Working Brand Identity

## Direction

Bold lowercase wordmark, strong and simple rather than decorative. The original converging-ray structure remains the distinctive brand device. The dot after `converge` is a mint accent.

**Wordmark construction:** Inter Display ExtraBold letterforms converted to SVG paths. This keeps the logo’s appearance consistent without requiring users or browsers to install a font file.

## Colour palette

| Token | Hex | Use |
|---|---|---|
| Deep Green | `#137C79` | Main wordmark on light backgrounds |
| Mint Green | `#48B99A` | Converging rays and dot |
| Night Forest | `#0B1110` | Main dark interface surface |
| White | `#FFFFFF` | Wordmark for dark backgrounds |
| Charcoal | `#101A16` | Monochrome alternative on light backgrounds |
| Pale Mint | `#E6F5EC` | Soft supporting background |

## Logo files

- `converge-wordmark.svg`: primary deep-green logo for white/light backgrounds.
- `converge-wordmark-dark.svg`: white wordmark + mint rays for dark backgrounds.
- `converge-wordmark-white.svg`: all-white monochrome logo.
- `converge-wordmark-black.svg`: all-charcoal monochrome logo.
- `converge-wordmark-mint.svg`: all-mint alternative.
- `converge-header-lockup.svg`: compact horizontal dark-interface lockup.
- `converge-header-lockup-green.svg`: horizontal green lockup for light surfaces.
- `converge-icon-*.svg`: small icon variants.

## Usage

1. Prefer green on white/pale surfaces and white with mint on dark surfaces.
2. Keep clear space around the full logo; do not crop or stretch the rays.
3. Use the horizontal lockup in the application header where the full ray structure would be too small.
4. Keep the landing-page animation and approved interface intact while replacing only the logo asset.
